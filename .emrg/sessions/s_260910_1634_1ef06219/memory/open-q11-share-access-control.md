# 问题⑪ 分享链接的访问控制 —— ✅ 已答复（已并入项目决策⑪，本文件仅备查）

**宿主答复（2026-09-10）**：**A + D** —— 持链接即可访问（无需登录）＋ 可撤销／可设有效期，**不做密码**。

已落档为项目决策：`.emrg/memory/decision-share-access-control.md`（决策⑪）。

## 结论一句话
分享链接 = 长随机 token，**持有即可匿名只读访问**；可随时撤销、可设有效期；不设访问密码（避免传递凭证）。

## 原提问时的关键推论（均已确认成立）
- 场景含**给导师汇报** → 导师不会注册 → **匿名读路径必需**，纯"必须登录"不可行
- 与决策①「用户间完全隔离」不冲突：隔离约束**写**，分享只放开**读**，且仅限被显式分享的那一个计划
