# 决策①：部署形态 = 自托管多用户（用户隔离，无团队）

宿主 2026-09-10 回答：**「自托管、多用户。目前不需要有实验室、团队的概念。每个注册用户都是独立用户。」**

## 含义
- 需要一个**后端服务 + 数据库**（不是纯前端），可 `docker compose up` 自托管
- 有**注册/登录/账号体系**（原型 auth 屏有实际意义）
- **无团队 / 无组织 / 无协作空间**等概念——数据模型里不需要 team/org/role 层级
- 用户之间的数据**完全隔离**：每张业务表带 `user_id`，所有查询强制按 `user_id` 过滤
- 未确认（待问）：只读分享链接是否保留（原型有此功能，属跨用户可见，与"完全隔离"有张力）

## 已排除
- 纯前端 + IndexedDB + 用户自带 Key（选项 C）
- 公网 SaaS / 多租户计费（选项 D）
- 实验室团队共用与协作（选项 B 的团队层）
