# 协作方式：设计阶段一次只问一个问题

用户（argszero）在 papershelf 设计阶段明确要求：

- **一次只问一个问题**，每次只回答一个问题；不要把多个问题打包抛出。
- **设计过程中有疑问不要跳过**，随时提问、及时澄清，不要自行假设后继续。
- 提问前先对齐理解（复述原型/需求拆解），再问下一个问题。

推论：把大问题（如“部署形态”）拆成单点选择题逐个推进；问完一个后等待回答，不要连续输出后续问题。
