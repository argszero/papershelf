# 决策⑤：双向对比形态 = 左右并排双栏（不做上下堆叠）

宿主 2026-09-10 回答（问题 5）：先答 `AB`，追问澄清后明确 —— **「只要 B」**。

## 确定
- 对比形态 = **B：左右并排双栏** —— 屏幕一分为二，左英文、右中文
- **滚动联动 + 段落对齐**（按标记 ID 对齐，左块滚到某段，右块跟随）
- **不做 A（上下堆叠）** —— 原型 `lang-dual` 的「英上中下 + 中文左边框」方案**弃用**

## 保留自原型的部分
- 三态切换仍有意义，但形态变为：**并排对照 / 仅中文 / 仅原文**（单侧全宽）
- 块级 `{en, zh}` 双语模型（决策④的标记 zip 正好提供）

## ⚠️ 已知代价（**已由决策⑥消解**）
1. **长公式与跨栏大图**：并排双栏使单侧宽度减半 —— 但决策⑥ 确定每侧为**单栏流式**，不存在"跨栏"概念，宽度问题由响应式与公式折行解决，无需"通栏"特例。
2. 与原型 `doc-stage` 双栏保版式的关系 → 决策⑥ 已明确**不复刻 PDF 双栏**。

## 遗留问题（待澄清）
- **「保版式」的确切含义**：宿主满意的产物是**单栏仿期刊**（`.page` max-width 940px），而原型阅读器是**还原 PDF 双栏**（`span:full` 跨栏块）。左侧英文/右侧中文时，每一侧究竟是「单栏流式」还是「还原 PDF 双栏」？
