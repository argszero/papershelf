# 决策⑫：v1 功能范围 —— 只做「术语表对齐」，不做「图表中文说明」

宿主 2026-09-10 回答（问题 12）：**B**。

## 背景：原型四个转换开关，两个已被前置决策永久置为「开」
| 设置项 | 状态 |
|---|---|
| 保留公式为 LaTeX | ✅ 总是开（决策③：`<div class="eq">\[…\tag{N}\]`） |
| 段落级中英对照输出 | ✅ 总是开（决策④⑤：双语 HTML + 并排对照） |
| 术语表对齐 | **v1 做**（本决策） |
| 为图表生成中文说明 | ❌ v1 不做（缓到 v2） |

## 确定
- **v1 做「术语表对齐」**：用户维护译名表（如 `control barrier function → 控制障函数`、`direct ink writing → 直写成型`），转换时注入 prompt。
  - 成本近零（prompt 多一段），**直接决定精读的术语一致性** —— 领域术语固定译法，几十篇读下来不会各译各的
- **v1 不做「图表中文说明」**（VLM 看图出图注）
  - 理由：需引入**第二个多模态模型**、每图一次视觉调用、且**幻觉风险高于文本翻译**（会编造图中不存在的数字/趋势）
  - 留待 v2，届时需单独决策模型来源与幻觉护栏

## 关联
- 术语表需与决策④「标记穿透翻译」协同：术语注入发生在**分块翻译**的每个切片 prompt 中
- 术语表归属：按原型应属**计划级**（与决策⑦计划私有归属一致），仍待细化
