# 决策⑥：「保版式」= 内容保真（不还原 PDF 栏位）

宿主 2026-09-10 回答（问题 6）：**A —— 内容保真，不还原 PDF 栏位。**

## 确定
- 正文 **单栏流式**排列 = 与现有满意的产物一致（`.page` 仿期刊单栏）
- 「保版式」的含义 = **图在原位、公式编号与右对齐、章节层级、表格结构**均忠实于原文
- **不**复刻 PDF 的双栏栏位；原型 `doc-stage` 的 `span:full` 双栏保版式方案**弃用**

## 渲染模型（三决策叠加后的最终形态）
```
决策⑤ 左右并排  +  决策⑥ 单栏流式
→ 左侧：英文单栏 HTML  ┐
   右侧：中文单栏 HTML  ┘ 按块标记对齐，滚动联动
```
- 每侧一份独立单栏 HTML（决策④ 的 en/zh 双产物）
- 三态：并排对照 / 仅中文（单侧全宽）/ 仅原文（单侧全宽）
- **长公式与跨栏大图不再需要"通栏"特殊处理**——因每侧本身单栏流式，宽度问题由响应式与公式折行解决（撤销决策⑤中记录的代价项 1）

## 已消解的矛盾
原担忧「并排双栏 × PDF 双栏 = 屏幕四分」不再成立：两侧都是单栏流式。
